# ร่วมใจจัดการขยะ (Citizen x Government)

แอปความร่วมมือด้านการจัดการขยะระหว่างประชาชนและภาครัฐ — แจ้งจุดทิ้งขยะ แจ้งผู้กระทำผิด ติดตามสถานะ สะสม Social Credit และติดต่อเจ้าหน้าที่

## Tech stack

React 19 · TanStack Start / Router · Vite · TypeScript · Tailwind CSS 4 · shadcn/ui

## Development

ต้องมี [Bun](https://bun.sh) (หรือใช้ Node.js + npm แทนได้)

```sh
bun install
bun run dev      # http://localhost:8080
bun run build    # production build -> .output/
bun run lint
bun run format
```
